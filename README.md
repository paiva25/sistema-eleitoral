# sistema-eleitoral

Projeto desenvolvido em linguagem C como atividade acadêmica do curso de Sistemas de Informação.

## Sobre o projeto

Programa desenvolvido para simular uma apuração eleitoral, utilizando os votos informados pelo usuário para realizar os cálculos e apresentar os resultados.

## Conceitos utilizados

- Entrada e saída de dados
- Estruturas condicionais
- Estruturas de repetição
- Variáveis e tipos de dados
- Operadores matemáticos
- Lógica de programação

## Tecnologias

- Linguagem C
- GCC

## Objetivo

Praticar estruturas condicionais, estruturas de repetição e lógica de programação por meio da criação de uma simulação de apuração eleitoral.
